# 把 AI 变成你的第二大脑 🧠

> WorkBuddy 上手 · 个人知识库搭建 · Skill 定制 —— 一篇写给同学的学习分享

**👉 在线阅读：<https://wwwwwjwwwww.github.io/workbuddy_study/>**

## 这是什么

我在实习过程中跟 AI 工具打交道攒下来的一些经验，整理成一篇长文分享给班里的同学。内容分三块：

- **Part 1 · 认识 WorkBuddy**：从零开始的使用指南——免费额度、充值时机、自定义指令、计划模式、工作空间、省 token 技巧
- **Part 2 · 搭建个人知识库（第二大脑）**：为什么建、RAG / LLM Wiki 是什么、为什么选 Obsidian、五步搭建法、可直接复制的「口令」模板
- **Part 3 · 打造你自己的 Skill**：Skill 的构成、十句口令从找现成到魔改成自己的版本、安全红线

网页版带**侧边目录**，点击任意章节可直接跳转，手机端也适配。
